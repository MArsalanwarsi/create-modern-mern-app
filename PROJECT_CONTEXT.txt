2. PROJECT PURPOSE
--------------------------------------------------------------------------------
create-modern-mern-app is an interactive CLI generator published to npm that 
scaffolds full-stack MERN (MongoDB, Express, React, Node.js) applications in 
seconds with production-ready architecture.

Key Highlights:
- Sliced layout architecture (Navbar, Sidebar, Footer, Header).
- Public website pages (Home, About, Contact) and admin dashboard pages (Overview, Settings).
- Full Vite React frontend with 4 variants (including React 19 Compiler).
- Express + MongoDB backend with proper separation of concerns (models, controllers, 
  routes, config, middlewares, utils) supporting native ES Modules or TypeScript.
- Granular optional library selection (Tailwind, Shadcn UI, Redux Toolkit, Toastify, 
  CORS, Multer, Cloudinary, Nodemailer) with zero dead code.

3. INTERACTIVE CLI WIZARD STEPS
--------------------------------------------------------------------------------
1. Project Name:
   - Validates non-empty input.
   - Performs inline collision check (warns if target folder exists and is non-empty).
   - Sanitizes name for npm rules (lowercased, valid characters).
2. Frontend Variant:
   - JavaScript
   - JavaScript + React Compiler (React 19 memoization babel plugin)
   - TypeScript
   - TypeScript + React Compiler
3. Frontend Packages (Multi-Select):
   - Tailwind CSS
   - Shadcn UI (components.json, utils, sample Button)
   - Redux Toolkit (store, counter slice, Provider)
   - React-Toastify (ToastContainer pre-mounted)
   (Note: React Router DOM v7 is built-in as core to power nested layouts).
4. Backend Language:
   - JavaScript (Native Node.js ES Modules, node --watch)
   - TypeScript (tsconfig.json, tsx watch runner, express types)
5. Backend Add-ons (Multi-Select with Express + MongoDB/Mongoose core):
   - CORS
   - dotenv
   - Multer (disk storage file uploads)
   - Cloudinary (cloud asset storage)
   - Nodemailer (SMTP email service)
6. Dependency Installation:
   - Option to auto-install dependencies in root, client, and server, or output manual commands.

5. ROOT SCRIPTS IN GENERATED APPS
--------------------------------------------------------------------------------
- npm run dev: Concurrently starts client (port 3000) and server (port 5000)
- npm run dev:client: Starts Vite client dev server
- npm run dev:server: Starts Express backend server with live reload
- npm run build: Builds both frontend and backend for production
- npm run install:all: Installs all dependencies across root, client, and server
