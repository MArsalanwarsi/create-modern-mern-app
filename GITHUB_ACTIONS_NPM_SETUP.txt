================================================================================
HOW TO CONNECT GITHUB ACTIONS TO NPM FOR AUTOMATIC PUBLISHING
================================================================================

This guide walks you through the 2-minute one-time setup so that pushing a 
new version to GitHub automatically tests and publishes your package to npm.

Direct Repository Link:
https://github.com/MArsalanwarsi/create-modern-mern-app

--------------------------------------------------------------------------------
STEP 1: GENERATE AN NPM ACCESS TOKEN
--------------------------------------------------------------------------------
1. Open your browser and go to:
   https://www.npmjs.com/settings/tokens

2. Log in to your npm account (arsalanwarsi).

3. Click the "Generate New Token" button in the top right.

4. Select "Granular Access Token" (or "Automation Token"):
   - Token Name: github-actions-publish
   - Expiration: Choose your preference (e.g. 90 days, 180 days, or 1 year)
   - Permissions (under "Packages and scopes"):
       * Select: "All packages"
       * Access level: "Read and write"

5. Click "Generate Token" at the bottom of the page.

6. IMPORTANT: Copy the token string immediately (it looks like npm_xxxxxxxx).
   You will not be able to see it again once you leave the page.

--------------------------------------------------------------------------------
STEP 2: ADD THE TOKEN TO GITHUB SECRETS
--------------------------------------------------------------------------------
1. Go directly to your GitHub repository secrets page:
   https://github.com/MArsalanwarsi/create-modern-mern-app/settings/secrets/actions

   (Or navigate manually: GitHub Repo -> Settings -> Secrets and variables -> Actions)

2. Click the green "New repository secret" button.

3. Fill in:
   - Name: NPM_TOKEN
     (NOTE: Must be uppercase and spelled exactly as NPM_TOKEN)
   - Secret: Paste the npm token you copied in Step 1.

4. Click "Add secret".

--------------------------------------------------------------------------------
STEP 3: HOW TO RELEASE UPDATES AUTOMATICALLY
--------------------------------------------------------------------------------
Once the secret is added, you never need to run `npm publish` on your local machine again!

Whenever you want to release a new version:

1. In your local repository, bump the version:
   npm version patch    # For bug fixes / small tweaks (e.g. 3.0.0 -> 3.0.1)
   npm version minor    # For new features (e.g. 3.0.0 -> 3.1.0)
   npm version major    # For breaking changes (e.g. 3.0.0 -> 4.0.0)

2. Push to GitHub:
   git push origin main
   git push --tags origin main

3. Watch it publish:
   - Go to https://github.com/MArsalanwarsi/create-modern-mern-app/actions
   - You will see the "Publish to npm" workflow start automatically.
   - It will checkout the code, install dependencies, run your 9 tests, 
     and publish the new version directly to npm!

--------------------------------------------------------------------------------
MANUAL TRIGGER OPTION
--------------------------------------------------------------------------------
You can also trigger a publish manually anytime from the browser:
1. Go to: https://github.com/MArsalanwarsi/create-modern-mern-app/actions/workflows/publish.yml
2. Click "Run workflow" -> select branch "main" -> click "Run workflow".
